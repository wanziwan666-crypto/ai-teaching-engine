# AI Teaching Engine 🧭

> AI 家教五步教学术——讲→练→诊断→干预→复盘，零依赖 AI 辅导引擎

给它任何一道数学题，它不会直接给答案，而是用五步循环把孩子**教到懂**。

## 五步教学法

```
讲（EXPLAIN）→ 练（PRACTICE）→ 诊断（DIAGNOSE）→ 干预（INTERVENE）→ 复盘（REVIEW）
```

| 步骤 | 做什么 | 核心原则 |
|------|--------|---------|
| 讲 | 一步步引导提问 | 绝不给答案，每步只问一个问题 |
| 练 | 分步出题收集过程数据 | 拆成和讲解一样多的步骤 |
| 诊断 | 五类卡点定位 | 精确到"第几步、什么类型的错误" |
| 干预 | 针对性纠错 | 指出方向，不给正确算式 |
| 复盘 | 沉淀可迁移方法 | 从具体题提炼通用策略 |

诊断发现没懂？回到"练"出一道新题重新走，最多循环两轮。

## 五类卡点诊断

按"越根本越先查"的顺序诊断（命中即归类）：

| 类型 | 典型表现 |
|------|---------|
| 无从下手 | 各步空着，全选"还没想好" |
| 审题理解错误 | 读错或看漏题干条件 |
| 方法/概念偏差 | 方法层出错：用错数量关系，或关系对但路径绕 |
| 过程跳步 | 方法路径都对，漏掉关键中间步骤 |
| 计算失误 | 方法全对，纯粹某步算错数 |

> **为什么不是六类**：「概念混淆」和「方法选择错误」要区分的是学生脑子里的理解状态，分步作答里往往看不出来，且两者的干预同为"补讲"。所以诊断层合成一类，"关系错 / 路径绕"的区分下沉到干预时看具体作答再判。
>
> **计算失误排最后**：只有方法、路径、步骤全对时才归它，避免把方法层问题误诊成粗心。

## 快速开始

### 安装

复制整个目录到你的 agent skills 路径：

```bash
cp -r ai-teaching-engine ~/.agents/skills/
```

支持 opencode、Claude Code、Cursor、WorkBuddy 等任何 agent 环境。

### 使用

对话中说：

> "教我这道题：鸡兔同笼，头10脚26，鸡和兔各几只？"

引擎会自动启动五步循环。

### 文件结构

```
ai-teaching-engine/
├── SKILL.md          # 行为规则（状态机 + 各阶段约束）
├── prompts.js        # 各阶段行为模板
└── problem-types/    # 题型骨架库
    ├── _schema.md    # 如何编写新题型
    ├── 鸡兔同笼.md
    ├── 相遇问题.md
    └── 工程问题.md
```

零 npm 依赖，零 pip 依赖，零外部服务。

## 工作原理

1. **SETUP**：分类题目 → 加载/生成解题骨架 → 创建教学面板
2. **EXPLAIN**：每轮输出一张 HTML 卡片（含 SVG 配图）+ chat 引导提问
3. **PRACTICE**：分步选择题/填空题，HTML 表单一次性提交
4. **DIAGNOSE**：对照标准答案逐步检查，定位卡点类型
5. **INTERVENE**：针对性引导，纠正后出新题验证迁移
6. **REVIEW**：复盘卡片（总结 + 下次怎么想 + 鼓励）

### 教学面板

每轮写 HTML 到 `~/Downloads/ai-teaching-card.html`，包含：
- SVG 可视化配图（圆点/箭头/标注）
- 进度条
- 完整对话历史（不压缩）
- 练习表单（提交后 JSON 复制到剪贴板）

学生浏览器打开面板，在 agent 对话中互动。

## 添加新题型

参考 `problem-types/_schema.md`，创建 `.md` 文件定义：

- 分类信号（怎么识别这类题）
- 解题骨架（3-5步，每步标注核心点、练习类型、讲解红线）
- 题型特有注意点

## 已知限制

- 仅支持**纯文字题**（条件可用文字完整描述）
- 不支持看图题（几何图形、图表数据、空间推理）
- SVG 配图为教学示意，不还原原题图片
