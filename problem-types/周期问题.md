# 周期问题

## 分类信号
- 按**一定规律重复排列**，问第 N 个是什么（图形／颜色／字母／数字循环）
- "照这样排下去"／"依次重复"／"按此规律"
- 求第 N 天是星期几、第 N 个月是什么季节
- 已知今天星期几，问 N 天后星期几
- 循环小数的第 N 位数字是几

## 适用范围
- 用：有固定重复单元的排列，求第 N 项是什么，或求前 N 项里某类有几个
- 不用：等差数列求第 N 项（不是重复而是递增，需单独骨架）、不重复的规律题（如平方数列）
- 判别标准：**能找到一个"最小重复单元"**，整串就是它反复出现。找不到重复单元的就不是本题型

## 解题骨架

| 步 | 名称 | 核心点 | 练习类型 | 练习选项/提示 | 讲解红线 |
|----|------|--------|---------|-------------|---------|
| 1 | 找出重复单元 | 最小的那一组，往后就是它一遍遍重复 | fill | 写出重复的那一组是什么 | 铺垫只念题目给的排列，"重复单元是哪几个"必须学生自己圈出来 |
| 2 | 数出周期长度 | 这一组里有几个，就是几个一循环 | fill | 写出周期长度 | 不能替学生数 |
| 3 | 用除法定位 | 第 N 个落在第几轮、这一轮的第几个——关键看**余数** | fill | 写出算式并求出得数（商和余数都要） | "为什么用除法／余数代表什么"是全题灵魂，不能由老师说破 |
| 4 | 由余数对应回答并检验 | 余数是几就对应重复单元里第几个；**余数为 0 对应最后一个** | choice | 余数几就是第几个/余数0对应最后一个/还没想好 | "余数为0该怎么办"必须学生自己想通，这是本题型最大的坑 |

## 题型特有注意点

- **第4步"余数为 0"是本题型第一高频错误，也是唯一真正的难点。** 7 个一循环，问第 14 个：14÷7＝2 余 0，对应的是重复单元里的**第 7 个（最后一个）**，不是第 0 个也不是第 1 个。这属「方法/概念偏差」（对余数含义理解有偏），干预要用"正好排满整轮，所以停在最后一个"来重建，**绝不能直接给"余0取最后一个"这条规则**——给了就是背规则而不是懂。
- **第1步找错重复单元会让后面全错但看起来很顺。** 比如"红黄黄红黄黄"，重复单元是"红黄黄"（3个）而不是"红黄"（2个）。学生圈错属「审题理解错误」，干预要带他把排列往后多写几项，自己验证单元对不对。
- **星期几类题要小心起点。** "今天星期三，再过 20 天是星期几"——20÷7＝2 余 6，是从星期三**往后数 6 天**，不是"第6天=星期六"。起点不是星期一时容易错，属「方法/概念偏差」。
- **"前 N 项里有几个红球"是反向问法**，仍用本骨架：先算完整轮数（商），每轮有几个红球，再补上余数那部分零头。这类题第3步的商和余数**都要用上**，而正向问法只用余数——这是两类问法的关键区别。
- 数字循环／循环小数完全同构（"0.363636… 第 20 位是几"），用同一骨架。
- 不要考"什么叫周期／这叫什么规律"——第1步问的是**哪几个在重复**，不是问术语。
